The extension icon and wordmark were generated with the built-in ImageGen tool. The bundled UI uses the mark and a transparent monochrome wordmark in both themes.

## Prompts

**Extension mark**

> Use case: logo-brand. Create a minimal, distinctive Chrome app icon for XScroll, independent software for scrolling through videos. The icon symbol is an abstract vertical film strip made of two vertically stacked short rounded frames, offset sideways by a small amount. The upper white outlined frame contains a solid small white play triangle. The lower frame is a single short solid white curved line, suggesting the next clip. This must be ONE bold compact silhouette readable at 16 pixels on a matte charcoal near-black rounded square that fills the canvas, with transparent area outside the rounded square. Strong clean white shapes, no texture. Do not include any letter, any letter X, any intersecting diagonal strokes, any third-party logo, any text, or any blue. Flat graphic in black and white only.

**Wordmark**

> Use case: logo-brand. Create a professional production wordmark for a browser extension. Output only the exact brand name XScroll, capital X and S and lower-case croll, as flat, solid pure BLACK (#000000) clean text on a pure WHITE (#FFFFFF) perfectly uniform background. Wide horizontal composition. Precise contemporary geometric sans serif semibold, optical spacing, slightly angular upper terminal on X for identity. Leave ample white margin all around. Render smooth crisp edges. No graphic or other words. Strict clean untextured binary black-and-white artwork. No shadows, decoration, colored pixels, erosion or transparency.
